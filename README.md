# Market Pulse

A personal market-signals dashboard for the Market Pulse Supabase project.

## Security

- The repository contains no API keys or secrets.
- The live Vercel deployment must use Vercel Authentication with **All Deployments** protection.
- The dashboard calls a same-origin serverless API route. That route calls the Supabase `rankings` Edge Function using server-only encrypted environment variables.
- Do not move `MPULSE_READ_SECRET` into browser code or any `NEXT_PUBLIC_*` variable.
- The Supabase Edge Function returns only the current day's ranking rows and requires the shared secret.

## Data and scoring

The board reads the `daily_rankings` rows generated by the Supabase pipeline. The score is the experimental momentum/liquidity score (70% momentum, 30% approximate dollar turnover). It does not include news sentiment or a historical backtest and is not a recommendation to buy or sell.

The collector runs every three hours. Ranking refreshes are scheduled 30 minutes after each collection run.

## Local development

This is a static HTML dashboard with a Vercel serverless API route. Set the two variables from `.env.example` in the local Vercel environment, then run `vercel dev`.

## Vercel environment variables

Set both variables for production, preview, and development:

- `MPULSE_RANKINGS_URL`: Supabase Edge Function URL ending in `/functions/v1/rankings`.
- `MPULSE_READ_SECRET`: the server-only shared secret used to authorize the Edge Function request.
